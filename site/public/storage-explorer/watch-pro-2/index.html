About this reference

Storage layout

The watch has 128 MiB of NAND and a separate 4 MiB NOR chip. NOR contains boot code, recovery, the main firmware and configuration. NAND contains resources, persistent history, logs and a writable filesystem.

NAND offsets refer to the 123 MiB logical address space provided by the flash translation layer (FTL). The remaining 5 MiB supports translation metadata and block management. NOR offsets are physical chip offsets. All sizes use binary units.

Sources and coverage

Firmware files come from the stock 1.0.0.73 update package. Partition boundaries, driver layouts and device-capture findings are identified separately in the region inspector. A known reservation or valid checksum does not establish factory contents or currently available space.

The stock package does not include every storage region. Undocumented fields and intervals remain marked. Installed applications, personal values and raw log contents are not included.

Reference versions

Stock package: 1.0.0.73. Device capture: patched firmware based on 1.0.0.73, loader package v1 (ABI 1.0), application stub 8. Version metadata was checked over BLE on 21 Nov 2026. Package version numbers are not assumed to be release names.
