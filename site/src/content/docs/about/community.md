FMC brings together people building tools, apps and watch faces for CMF devices.
Code, design, documentation, research and device testing all contribute to the
projects.

| Place | What you will find |
|---|---|
| [FMC](https://fmc.tools) | The watch-face editor and gallery, app store and firmware downloads |
| [FMC on GitHub](https://github.com/fmctools) | Project source, issues, pull requests and development discussions |
| [FMC Community on Discord](https://discord.gg/KnAFruMabJ) | Community questions, project discussion and shared findings |
| [r/CMFWatchMods on Reddit](https://www.reddit.com/r/CMFWatchMods/) | Watch modifications, project showcases and community discussion |

## Questions and problem reports

For setup and common failures, start with [Troubleshooting](/getting-started/troubleshooting/).
Discord and Reddit provide places to discuss experiments and ask the community.
For a reproducible problem in CMF Watch Utils, open a
[GitHub issue](https://github.com/fmctools/cmf-watch-utils/issues).
Include the model, firmware version, operating system and steps that reproduce it.
State whether it occurred in the browser, desktop QEMU or on a physical watch.

Remove personal device identifiers, pairing keys and private notification content
before sharing logs. Community advice and emulator results do not guarantee
physical recovery after a failed update.

## Contributing

The [contributor guide](/getting-started/contributing/) covers local setup and
checks for documentation, Python tools and emulator work. Project-specific
instructions live with each repository in the [FMC organization](https://github.com/fmctools).
